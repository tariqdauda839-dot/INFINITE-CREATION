# Infinite Creations

Infinite Creations is a browser-based tech marketplace, business simulator, open-world 3D experience, and life-simulation game designed to run on GitHub Pages.

## Features

- Tech marketplace and product search
- Customization engine and live invoice simulator
- Demo authentication flow
- AI assistant chat panel
- Arcade game
- 3D open-world living world exploration
- Gas and electric vehicles
- Supercars and hypercars
- Bikes, super bikes, and hyper bikes
- School, university, work, and house progression simulation
- Anime-inspired fictional powers
- Local virtual money simulation
- GitHub Pages deployment ready

## Files

- `index.html` — main marketplace and app shell
- `open-world.html` — 3D exploration game and world systems
- `world-expansion.js` — vehicle, life, and power simulation logic

## Run locally

Open `index.html` directly in a browser.

For the 3D world, open `open-world.html` directly or via a local web server.

## GitHub Pages

1. Push this repository to GitHub.
2. Go to Settings → Pages.
3. Set Source to `Deploy from a branch`.
4. Select the default branch and `/ (root)` folder.
5. Save.

Your app will be available at:

```text
https://tariqdauda839-dot.github.io/INFINITE-CREATION/
```

## Notes

- This is a fictional demo project.
- No real payment system, real authentication, or real financial information is used.
- For production, use a secure backend with Stripe, Firebase Auth, or Supabase.
